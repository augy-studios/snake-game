Hard moves faster and scores half as much again; Easy is slower and scores less. A time limit ends the game when it runs out, and a fruit timer moves any fruit you do not reach in time. Both add to the points. Changes count from the next game. Settings are kept in this browser.

Play with others

Everyone has to be on the same network: the same wifi, or a hotspot on one device that the others join. Up to four play, together or against each other, and anyone else watches and can drop walls in the way or extra fruit.
